# 0006 默认不持久化 Prompt 与 Response

- 状态：Accepted
- 日期：2026-07-30

## 背景

Prompt 和 Response 可能包含个人信息、源代码、合同、密钥和业务数据。为了调试而默认保存正文会扩大泄漏面，也增加跨租户和合规风险。

## 决策

MVP 默认只保存：长度、规范化哈希、内容分类、模型/策略版本、Token、状态和延迟。日志、Trace、错误、Usage Event 和 ClickHouse 均不得包含正文。

后续若增加明文采样，必须由租户显式启用，定义用途、权限、保留期限、加密、删除和审计。

## 替代方案

- 默认全量保存：调试方便，但安全与合规风险不可接受。
- 完全不保留任何摘要：隐私更强，但难以去重、缓存和分析异常。

## 后果

- 部分问题无法通过历史正文复现，需要 Mock/脱敏采样机制。
- 安全边界更小。
- 缓存与评测功能必须单独获得内容处理授权。

## 验证方式

P12 自动扫描日志、Trace、错误和存储；跨租户与留存策略测试。
