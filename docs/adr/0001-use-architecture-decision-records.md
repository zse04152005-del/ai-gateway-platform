# 0001 使用架构决策记录

- 状态：Accepted
- 日期：2026-07-30
- 决策者：项目维护者

## 背景

AI 网关涉及失败语义、流式处理、预算、计量、隐私和多种基础设施。如果只在代码或聊天中保留理由，后续很难判断某项行为是有意设计还是偶然实现。

## 决策

对影响公开接口、事件、数据模型、可靠性、安全、部署或关键技术选择的事项创建 ADR。Accepted ADR 不直接改写历史；新决策通过新的 ADR 标记取代关系。

## 替代方案

- 只在 README 记录：内容会过度集中且难以追踪决策演进。
- 只依赖提交记录：无法保证背景、替代方案和验证标准完整。

## 正面后果

- 关键权衡可复盘。
- 实现和评审拥有明确验收依据。
- 面试或开源协作时能解释设计理由。

## 负面后果与风险

- 增加文档维护成本。
- 如果实现变化却不更新 ADR，文档会失真。

## 验证方式

阶段门禁检查涉及重大决策的代码是否有对应 ADR，且 ADR 与实际行为一致。
