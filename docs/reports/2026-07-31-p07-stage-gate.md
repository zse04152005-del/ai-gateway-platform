## 3. 阶段门禁逐项证据

### 3.1 普通与异常 SSE Fixture

通过：

- SSE 网络分片、CRLF、comments、`data:` 聚合、未知字段、无效 UTF-8、行/事件/字段上限；
- Writer 的 Content-Type、Cache-Control、Connection、nosniff、Flush、终态和写失败；
- Mock/OpenAI Adapter 的正常 `[DONE]`、完整/缺失 Usage、未知扩展、Malformed Chunk、HTTP Error；
- 混合压力中的正常结束、上游无 `[DONE]` 断流、长 TTFT、随机取消和慢消费者。

包装底层 `io.EOF` 的 ProtocolError 不会被当作干净结束；只有精确 `io.EOF` 执行正常 Finish。

### 3.2 客户端取消后资源在 SLO 内释放

通过：

- P07-T06 真实 HTTP 测试每轮 25 个取消，会话重复 20 轮共 500 次；
- 阶段 `internal/streaming -count=20` 再执行 500 次专用取消与 3000 个混合压力会话；
- `CancellationObservedAt`、`UpstreamReleasedAt`、非负传播耗时全部存在；
- Provider request Context 在 1 秒内取消；连接归零；GC 后 Goroutine 回到基线噪声窗口；
- 慢客户端 Buffer 高水位不超过 4 Chunk/16 KiB，背压有界且无溢出。

### 3.3 部分失败不丢失 Attempt 和 Usage

通过：

- 事务状态链 `created→connecting→headers_received→streaming→partial_failed` 完整；
- GatewayRequest=`partial_failed`，RouteAttempt=`partial_failed`；
- `headers_received_at <= first_byte_at <= ended_at`；
- end reason、error category/code、Provider Request ID 保留；
- 已知 Output Token 持久化，未知 Input Token 保持缺失而非 0；
- Provider Final、累计 Chunk、本地 Estimate 分轨，终态缺失按可信优先级回退；
- 首包后普通/可重试失败、重复 Mark、终态覆盖和 Usage meter 回退全部拒绝。

真实 PostgreSQL `TestGatewayExecutionLifecycle -count=20` 验证上述事务、约束与事件版本。

## 4. 安全与语义不变量

- Prompt、响应正文、Provider Secret、Endpoint 与 Raw Usage Evidence 不进入 Execution Summary/压力指标；
- Provider/Gateway heartbeat 不满足首模型 Token，也不重置错误的时钟；
- 首包前只有受信 first-token timeout 可申请 failover；首包后备用 Starter 永不调用；
- 旧 Attempt 迟到 Chunk 不能写入新 Attempt 的响应；
- Raw Usage Evidence 保持不可变，普通 JSON/日志只输出 SHA-256 和字节数；
- 缺失计量不伪造 0，累计 Usage 不重复相加。
